Mobile App Traffic Audit Using a Proxy Tool

This project explains how mobile app traffic can be observed and analyzed by routing device requests through an interception proxy. It is designed for academic demonstration, ethical testing, and security learning.

Project overview

Abstract

This project studies how a proxy tool can be used to monitor network traffic generated by a mobile application. By redirecting device communication through the proxy, the auditor can examine requests, responses, headers, API endpoints, and selected transport security behaviors.

Ethical note: this project is intended only for authorized testing, lab apps, demo apps, or your own applications. Intercepting third-party app traffic without permission is not appropriate.
Environment

Required tools

Tool 02

Tool 03

Network setup

Wi-Fi connection, laptop IP address, proxy port, and proxy CA certificate if HTTPS inspection is required.

Procedure

Methodology

The project can be demonstrated as a practical security audit workflow with clear, explainable phases.

Step 1: Install and start the proxy tool on the laptop.
Step 2: Connect the mobile device to the same Wi-Fi network as the laptop.
Step 3: Configure the mobile device proxy settings using the laptop IP address and listening port.
Step 4: Install the proxy CA certificate on the mobile device to inspect encrypted HTTPS traffic in an authorized test setup.
Step 5: Launch the target app and observe captured requests, responses, domains, methods, headers, and response codes.
Step 6: Document findings such as insecure API calls, unencrypted data, verbose error responses, or certificate pinning behavior.

Constraints

Limitations

Not every mobile app can be intercepted easily, especially when extra transport protections are enabled.

Certificate pinning

Some apps reject interception proxies even when the CA certificate is installed.

Encrypted payload logic

Apps may add application-layer encryption beyond normal HTTPS.

Legal scope

Testing must remain limited to authorized applications and lab environments.

Exam support

Viva questions and answers

These points are useful for viva, seminar, and record submission.

1. What is a proxy tool?
A proxy tool is an intermediate application that receives and forwards network requests between a client and server so that traffic can be inspected or modified during authorized testing.
2. Why is it used in mobile app auditing?
It helps the tester observe how the mobile app communicates with backend services and whether data is exposed or weakly protected.
3. Why is a CA certificate needed?
It allows the proxy to decrypt HTTPS traffic in a controlled environment by making the device trust the proxy for inspection.
4. What is certificate pinning?
Certificate pinning is a defense mechanism where the app trusts only specific certificates or keys, preventing ordinary proxy interception.
5. What can be identified in the audit?
Endpoints, methods, headers, session tokens, response behavior, and some transport security weaknesses.
6. What is the main limitation?
Some apps use pinning or additional encryption, which blocks normal interception and requires advanced authorized testing methods.
